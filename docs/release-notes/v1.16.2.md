## Downloadable extension builds

GitHub Actions now builds the extension and publishes its ZIP and SHA-256
checksums in GitHub Releases. Download `authenticator.zip`, extract it and
select the extracted directory with **Load unpacked** in `chrome://extensions`.

This version includes the removal of Pro billing, account limits, analytics,
remote banners and backups hosted by the upstream operator. Existing local
account features, encrypted exports, local backups and optional Google Sync
remain available. Obsolete billing and telemetry metadata is cleaned up locally.
